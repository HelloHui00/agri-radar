【科研】

1. 高光谱反射率中解耦植被—土壤交互作用。面向冠层光谱混合机理，为作物参数反演与干旱/长势监测提供更干净的光谱信号。 RSE
2. CatBoost–Transformer 框架从 GOES-R 逐小时反演多参数多波长气溶胶。静止轨道高频大气校正思路，对农业遥感时序预处理有参考价值。 RSE
3. 去噪引导的 SAR 基础模型。以去噪为预训练任务构建 SAR 大模型，可迁移至洪涝、作物结构监测等下游任务。 ISPRS J P&RS
4. SOVS-Net：跨模态对齐+层级语义推理的 SAR 开放词表分割。开放词表能力对灾害应急中"未见类别"目标提取有潜力。 ISPRS J P&RS
5. UniPoly：遥感影像多边形与折线统一实例级提取框架。田块边界与地块矢量化的统一建模思路。 ISPRS J P&RS
6. 原型度量学习用于 Sentinel-1 SAR 海冰类型制图。多源辅助数据+度量学习的分类范式，可借鉴到作物类型/受灾类型制图。 ISPRS J P&RS
7. TSE-Net：单幅遥感影像半监督单目高度估计。半监督高程反演，对地块尺度地形与作物高度估计有参考意义。 ISPRS J P&RS
